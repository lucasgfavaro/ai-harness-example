# Home Assistant API

Modulo Spring Boot que simula dispositivos de una casa en memoria: luz de jardin, cerradura, persianas y termostato. No usa hardware ni servicios externos.

Este modulo forma parte del monorepo. Consulta [`../README.md`](../README.md) para levantar ambos servicios con Docker Compose y ejecutar todas las pruebas.

Desde la raiz:

```powershell
.\gradlew.bat :home-assistant-api:bootRun
```
